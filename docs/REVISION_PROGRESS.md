| 16 | Verifiable importers + patch updater | done | **Importers:** `buildImporter.ts#parseBuildGuide` now emits a structured `fields: ImportedField[]` (per top-level field: detected value, source excerpt — a real substring of the fetched content, never fabricated — method, confidence, `needsConfirmation`) alongside the existing `detected: string[]` (kept for backward compatibility). New `catalog_versions` table + `GET/POST /api/admin/patch/versions|stage|:id/activate|:id/rollback`. Frontend: new "Modifier catalog patch updater" panel in `KnowledgePage.tsx` (stage form + version list with regression/diff results and Activate/Rollback actions).
